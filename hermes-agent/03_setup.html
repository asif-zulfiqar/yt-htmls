SETUP GUIDE · Hermes + Owl Alpha
3 COMMANDS · UNDER 5 MINUTES
// Linux · macOS · Windows (WSL2)
Get Running in 3 Commands
No prerequisites. No manual config. Installs everything automatically.
1
Install
Install Hermes Agent
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
Installs Python 3.11, clones the repo, sets up everything. No sudo needed. Works on Linux, macOS, and WSL2.
~2 min
2
Configure
Run Setup Wizard → Select Owl Alpha
hermes setup
Interactive wizard → Select: OpenRouter → Get free API key at openrouter.ai (no credit card) → Model: openrouter/owl-alpha
~3 min
3
Launch
Start Hermes
hermes
Full CLI opens. Owl Alpha active. Memory, tools, and skills ready. Type your first task in plain English.
Instant
// Switch models anytime
$ hermes model
Shows full model list. Select any OpenRouter model. Change takes effect immediately.
$ hermes update
Pull latest changes + reinstall. Run anytime for new features.
// Optional: connect messaging platforms
$ hermes gateway setup
Connects Telegram, Discord, Slack, WhatsApp, Signal.
$ hermes gateway
Starts the gateway. Agent reaches you from anywhere.
⚠Windows users: Use WSL2 first. Native Windows support is experimental — not guaranteed to work.
